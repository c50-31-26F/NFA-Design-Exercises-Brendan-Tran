# NFA Design Exercises
Problems chosen from the N/DFA/RE Design exercises list (Problem #6–#24):
13. strings with at least 2 one's
14. strings of even length
17. strings with 3k one's (k ≥ 0)
20. 3k+1 one's, OR odd number of zero's
23. odd length, OR s = "01"

1. The problem that gave me the most trouble was problem 20. I had to scan at both paths when doing the hand-drawn tree.
2. Problem 13 surprised me when it branched out to seven leaves fully. It is because it was non-deterministic, each input can branch out to either choosing to go to the next state or stay on the same one.
